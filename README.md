# Ocean Dash

A one-button underwater runner. Jump the submarine over the sharks and collect coins.

## Download it

**[Download ocean_dash.html](../../releases/latest/download/ocean_dash.html)**, then double-click it. The whole game is that one file. It opens in your browser, runs offline and needs nothing installed.

## Controls

| Key | What it does |
| --- | --- |
| `Space` | Jump |
| `Space` or `R` | Restart after game over |

## For developers

Everything is in `ocean_dash.html`: the markup, the styles and the game code. Edit the file and reload the page.

To publish a new version, go to Releases, press "Draft a new release", type a new tag such as `v1.0.1` and press "Publish release". The workflow in `.github/workflows/release.yml` attaches the file by itself.
